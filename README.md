# Fitness Log Sync

Start with **START_HERE.md** for the Windows / Android Studio and Google Apps Script instructions.

A private Android app exports Samsung Health data through Health Connect to a dedicated Google spreadsheet. It has independent category reads, a durable SQLite upload queue, verified server acknowledgements, automatic catch-up, measurement change tracking, issue/recovery notifications and optional check-ins.

Included: Android Studio source project, dedicated Apps Script endpoint, Gradle wrapper bootstrap, setup guide, briefing monitoring instructions, and upload-script functional tests.

No credentials are embedded. Sleep duration and distance are excluded. The old Second Brain project is untouched.

This package contains source code, not a compiled APK. See START_HERE.md for completed validation and integration checks still requiring Android Studio and the phone.
